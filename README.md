# ラララム | 卒業制作紹介サイト

## 概要
教授向け・スマートフォン優先・縦スクロール1ページ完結の紹介サイトです。

- `index.html` をブラウザで開けば閲覧できます（画像は `assets/` フォルダを参照します）。
- HTML/CSS/JavaScriptのみで実装。外部ライブラリやネット接続は不要。
- ファーストビュー → コンセプト → 代表ステージの体験フロー → キャラクター → 世界観 → ゲームシステム → 制作・実現性 → 結び。
- 代表ステージの「01 焦り / 02 観察 / 03 工夫・突破 / 04 余韻」タブは操作できます。ゲーム本編ではなく、コンセプトを解説するWeb上の切り替えUIです。

## 画像について
`assets/` は企画段階のステージ構想イメージから一部分を切り出した画像です。ゲームの動作画面・完成版を示すものではありません。キャラクターの線画は、このサイト用の仮のシンボルです。

### 実際の素材に置き換えるとき
- メイン画像: `.art-main img`（ヒーローの右）
- ステージ例: JavaScript中の `stageData` の4項目 `img`（必要なら動画に差し替え）
- 世界観: `.world-item img`（3枚）
- キャラクター: `.char-portrait` 内のSVG（実際のイラストに差し替え）
- 実装確認: `.proof-card` 内の文章は実測・最新のテスト状況を確認のうえ更新

## 注意
- 代表ステージ「成長を急ぐ庭園」は説明用の設計案であり、実装済みステージの紹介ではありません。
- Unityの起動フロー・macOS開発ビルドへの言及は、これまで共有されたテスト・ビルドの記録に基づくものです。公開前に最新状況と合わせてください。
- ゲームによる心理的効果は実証済みという扱いにしていません。

## 配布
`index.html` と `assets` をそのままWebサーバーや静的ホスティングにアップロードできます。別途添付の `lalaram_onepage.html` は画像を含む単独HTML版です。
